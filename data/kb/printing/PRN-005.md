# Network printer is unreachable

Synthetic training article for the ServiceDesk Copilot demo. Not real vendor guidance.

## Check the address

Confirm the printer address matches the one on the device label. A printer that received a new address from the network will not answer at the old address even though it is powered on.

## Test from another device

Send a test page from a second computer on the same network. If the second computer can print, the problem is local to the first computer's queue rather than the printer.

## Escalate a network fault

If no computer can reach the printer, do not change network equipment. Record the printer address and the time the fault started, then raise a ticket for the network team.
