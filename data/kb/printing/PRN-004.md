# Install a Windows printer driver

Synthetic training article for the ServiceDesk Copilot demo. Not real vendor guidance.

## Use the signed package

Install the driver package approved for the office printer model. Do not download a driver from an unverified mirror. The package name and version are printed on the label attached to the printer.

## Add the printer

Open Settings, choose Printers and scanners, and select Add a printer. Pick the network printer by its queue name. If Windows finds the device automatically, accept the detected driver only when its name matches the approved package.

## Test the installation

Print the built-in test page. If the test page fails, remove the printer entry and add it again with the full queue name rather than the shortened device name.
